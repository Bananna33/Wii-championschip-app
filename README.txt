WII CHAMPIONSHIP — VERSION 8.1

FIXES
- Interaktion auf zentrale Click-/Touch-Verarbeitung umgestellt.
- Dynamische Buttons verlieren nach einem Re-Render keine Event-Handler mehr.
- Setup startet direkt mit vier Namensfeldern.
- Optional kann eine fünfte Person hinzugefügt werden.

TABLET / IPAD
- Größere Touch-Ziele.
- Einspaltiges Layout auf Tablets.
- Tabs bleiben auf kleineren Geräten oben erreichbar.
- Mario-Kart-Plätze werden über große 1/2/3/4-Tasten statt kleine Dropdowns eingetragen.
- Pro Rennen kann jeder Platz nur einmal vergeben werden.
- Wird ein belegter Platz neu gewählt, wird er beim bisherigen Fahrer automatisch entfernt.

WICHTIG
Auf iPad die App in Safari bzw. als installierte PWA öffnen.
Eine reine Datei-Vorschau innerhalb anderer Apps kann JavaScript blockieren.
