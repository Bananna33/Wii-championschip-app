WII CHAMPIONSHIP — VERSION 8.2

NEU
- Freies Durchsehen aller bereits verfügbaren Turnierabschnitte über die Fortschrittsleiste.
- "Zur aktuellen Runde" bringt sofort zurück zum aktiven Schritt.
- Vergangene Runden sind standardmäßig schreibgeschützt.
- Mit "Bearbeiten · ab hier neu" kann eine alte Runde korrigiert werden.
- Dabei werden alle später abhängigen Ergebnisse sauber gelöscht und das Turnier ab dieser Runde neu fortgesetzt.
- Einheitliche Gewinner-Auswahl: Bei jeder Wii-Sports-Resort-Begegnung stehen immer zwei klare Gewinner-Buttons UNTER der Paarung.
- Animierte Punkte in der Live-Tabelle: neue Punkte fliegen sichtbar vom Namen Richtung Punktestand, der Zähler zählt hoch.
- Animationen respektieren "Bewegung reduzieren".
- v8.1-Daten im lokalen Speicher können weiter geladen werden.
- Import akzeptiert auch ältere v8-Turnierstände und migriert sie intern auf v8.2.

TABLET / IPAD
- Große Touch-Flächen.
- Einspaltige Darstellung auf Tablets.
- Große 1–4-Tasten für Mario-Kart-Platzierungen.
- Tabs bleiben auf Tablets oben erreichbar.
- Keine externen Bilder oder Online-Abhängigkeiten für die Turnierlogik.
